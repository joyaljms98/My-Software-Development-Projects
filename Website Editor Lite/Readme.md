\# JJ's Web Editor



A powerful, in-browser editor that allows you to load and edit local HTML, CSS, and JavaScript projects directly. Get a live preview of your website and make changes with both a visual GUI and a full-featured code editor.

\## ✨ Key Features



\* \*\*Local Project Loading\*\*: Select a local folder and choose your HTML, CSS, JS, and even image files to start editing. The editor intelligently handles file selection and setup.

\* \*\*Dual Editing Modes\*\*: Seamlessly switch between two powerful editing panels:

&nbsp;   \* \*\*Visual Edit Panel\*\*: Click any element in the live preview to visually edit its properties like text content, colors, fonts, padding, and links.

&nbsp;   \* \*\*Monaco-Powered Code Editor\*\*: Switch to a professional code editor with syntax highlighting and a tabbed interface for your HTML, CSS, and JavaScript files.

\* \*\*Live Preview\*\*: See your changes reflected instantly in a live `iframe` preview panel right next to the editor.

\* \*\*Undo/Redo\*\*: Full history tracking for all your changes made in the visual editor, with Undo (`Ctrl+Z`) and Redo (`Ctrl+Y`) support.

\* \*\*Responsive Design\*\*: The editor interface itself is responsive and works well on different screen sizes.

\* \*\*Export as ZIP\*\*: Save your entire edited project as a downloadable `.zip` archive with a single click.

\* \*\*Preview in New Tab\*\*: Open your live preview in a separate browser tab for a full-screen view of your work.



\## 🚀 Getting Started



Since this is a client-side application, no installation is required.



1\.  Download the project files (`index.html`, `style.css`, `script.js`).

2\.  Open the `index.html` file in a modern web browser (Chrome is recommended for full folder selection support).

3\.  Click the \*\*"Select Folder"\*\* button and choose the directory containing your web project.

4\.  A new screen will appear. Select the specific files you want to edit and click \*\*"Load Selected Files"\*\*.

5\.  Start editing!



\## 🛠️ Technology Stack



\* \*\*Frontend\*\*: Vanilla JavaScript (ES6+), HTML5, CSS3.

\* \*\*Styling\*\*: \[Tailwind CSS](https://tailwindcss.com/) (via CDN) for rapid UI development.

\* \*\*Code Editor\*\*: \[Monaco Editor](https://microsoft.github.io/monaco-editor/) (via CDN), the same editor that powers VS Code.

\* \*\*File Packaging\*\*: \[JSZip](https://stuk.github.io/jszip/) (via CDN) for creating the downloadable ZIP file of the project.
